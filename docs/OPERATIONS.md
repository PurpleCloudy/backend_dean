# Эксплуатация

Основной путь установки приведён в README и использует официальный PostgreSQL17, SeaweedFS4.15, Qdrant1.15.5 и ClamAV1.4. API, исходный агент и Linux worker работают из одного образа приложения. Наружу опубликован только API на127.0.0.1:8000; остальные службы находятся в отдельной Docker-сети.

`python scripts/local_config.py` создаёт случайные локальные секреты. Флаг `--fixture-providers` явно выбирает детерминированные учебные модели. Для настоящего агента задайте OPENAI_BASE_URL, OPENAI_API_KEY, OPENAI_MODEL и BGE_URL. Отсутствующие настройки не заменяются фиктивным провайдером автоматически. Храните `.env.local` и `.local/s3.json` приватно; не включайте их в образ или репозиторий.

Начальная установка предназначена для новой базы. `scripts/initialize.py --synthetic` загружает предоставленные учебные данные только в пустую исходную схему и ставит будущие учебные приказы в обычную очередь от имени bootstrap-администратора. Для существующего задания повторный вызов помощника не создаёт дубль. Без этого флага устанавливается пустая рабочая база. Исходные `rebuild` скрипты удаляют базу и не используются для запуска приложения. Перенос данных из прежних экспериментальных версий не входит в этот проект.

`/health/live` показывает состояние процесса; `/health/core` проверяет базу; `/health/ready` также проверяет хранилище, поиск, модель эмбеддингов, актуальность антивирусных сигнатур и исходный агент. Недоступность зависимости отражается в readiness. ClamAV должен регулярно обновлять сигнатуры; устаревшая или недоступная база сигнатур блокирует публикацию загруженного файла.

Вход ограничивается раздельно по учётной записи и адресу клиента:10 и100 попыток соответственно за300 секунд. Настройки: LOGIN_ACCOUNT_LIMIT, LOGIN_IP_LIMIT, LOGIN_WINDOW_SECONDS. TRUSTED_PROXY_IPS по умолчанию пуст: произвольный X-Forwarded-For не меняет адрес клиента. При добавлении reverse proxy указывайте только его действительные адреса.

При обслуживании сначала остановите API, агент и worker: `docker compose --env-file .env.local stop api agent worker`. Обычный `down` сохраняет данные в томах. Не добавляйте `-v`, если данные нужны.

Резервная копия должна включать PostgreSQL и соответствующие исходные объекты S3 с неизменными ключами и контрольными суммами. Qdrant можно восстановить из готовых версий файлов. Проверяйте восстановление в отдельной пустой базе и бакете, прежде чем переключать приложение. Восстановленный worker запускайте только после проверки ссылок и состояния очереди.

Поддерживаемый worker работает в Linux-контейнере с ограничениями ресурсов парсера. Для локального Windows API используйте `python -m deanery_api.main`: он выбирает нужный asyncio event loop. Прямой запуск Windows worker запрещён приложением.

На текущем проверочном компьютере загрузка некоторых официальных образов завершалась сетевыми ошибками реестра. Для локальных испытаний использованы настоящие проверенные выпуски тех же служб в приватном override; это подтверждает протоколы служб, но не успешность загрузки официальных образов на этом компьютере. Приватный override не является альтернативной поставкой проекта.
