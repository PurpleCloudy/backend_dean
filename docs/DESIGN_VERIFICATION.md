# Проверка дизайна: независимый обзор, 10.10.2026

Статус текущего этапа: **независимый обзор кода выполнен, сборка разрешена; кликовая проверка заблокирована**. Изучены все 12 предоставленных пользователем PNG. Это исходные обрезанные изображения пользователя, а не новые снимки работающего приложения.

Поддерживаемый Windows Computer Use нашёл настоящее окно Chrome, но при чтении состояния остановил работу: не смог достаточно уверенно определить текущий URL для проверки правил доступа. После этого клики, ввод, вход и запросы модели не выполнялись. Другой браузер, headless, CDP и обход защиты не использовались. Backend отдельно сообщил о работоспособности локального стенда; это не подтверждает браузерные сценарии.

## Исходные наблюдения по изображениям пользователя

| Область | Наблюдение | Проверяемое исправление |
|---|---|---|
| Выбор документа | Две строки почти касаются границ карточки | Внутренние отступы, сближенные подписи карточки, равные промежутки, перенос длинного текста |
| Ответ агента | Состояние запроса показано отдельно | Проверка/копирование в одной строке и одинакового размера; доступные подробности |
| Ввод агента | По статичному снимку нельзя доказать очистку черновика | Принятая реплика очищается; отклонённый и новый черновики сохраняются |
| OLAP | Крупное вступление отодвигает выбор данных; нативное меню отличается от оформления | Компактный верх, согласованный dropdown, клавиатурное управление |
| Показатели OLAP | Начало второго столбца меняется между строками | Два выровненных столбца, перенос описаний, один столбец при узком окне |
| NULL-фильтр | Значение и «Не задано» выглядят одновременно доступными | NULL исключает обычный ввод и сохраняет правильный серверный предикат |
| Таблицы | Количество записей находится ниже «Добавить» | Общая ограниченная строка действий и количества |
| Ведомости | Фильтры требуют компактного размещения | Компактная версия общих фильтров без потери подписей/действий |
| Страницы | Подпись номера расположена над полем | Подпись, поле и переход в одной строке; границы и Enter сохраняются |
| Курсовые и ВКР | Вид работы визуально сливается с длинной дисциплиной | Более ранний перенос в пределах прежней ширины таблицы |
| Профиль | Фиолетовая подчёркнутая ссылка отличается от меню | Действие профиля соответствует оформлению соседних пунктов |

Двенадцатое изображение является точной копией одиннадцатого, с тем же меню профиля. Совпадение подтверждено содержимым файлов и SHA256; первоначальное отображение этого изображения в инструменте проверки выглядело обрезанным. Сохраняется существующий стиль приложения. Общая оценка дизайна, текущая адаптивность, контраст, анимация и скорость по этим обрезанным изображениям не подтверждаются.

## Матрица проверки после восстановления доступа

Проверка объединена по общим механизмам: загрузка всех основных семейств страниц, затем представительные сценарии таблиц, карточек, фильтров, пагинации, документов, OLAP и чата. Роли admin/staff/student проверяются там, где меняются доступ и поведение. Полный перебор каждого поля по всем ролям не планируется.

Все следующие проверки в текущем этапе **NOT RUN**:

- Вход, профиль, меню, перезагрузка, выход и изоляция пользователей.
- Студенты/группы: поиск, фильтр, пустая выдача, переход из группы; без приказов и изменений студентов.
- Расписание: таблица/неделя, группа/преподаватель/аудитория, сохранение пустого выбора.
- Работы, практика, заявки, сотрудники: загрузка, длинные строки, доступные действия и просмотр существующих карточек.
- Справочники и ведомости: общая строка действий, компактные фильтры, NULL, диапазоны, сброс и переход на страницу.
- OLAP: dataset, показатели, условие NULL, расчёт и раскрытие результата.
- Документы: происхождение, выбранная версия, длинные подписи и отмена выбора.
- Чат: строка копирования/состояния, подробности, очистка принятой реплики, сохранение отклонённого/нового черновика и история.
- Узкое настоящее окно Chrome: перенос, переполнение, доступность управления.

Новые естественные запросы реальной модели также **NOT RUN**: количество групп, студенты заданной группы, соединение таблиц и крупнейшие группы, регламент, факты TXT, сравнение нескольких документов, продолжение чата, безопасный предпросмотр предложения, уточнение неоднозначной фамилии, ранее выбранная неизменяемая версия. Предложения не исполняются. Ошибка модели фиксируется отдельно от ошибки приложения; неудачный запрос не подгоняется для успешного результата.

## Независимый обзор кода

Сопоставлены изменения с сохранённым исходным состоянием миссии; проверены вызывающие компоненты и общие стили. Подтверждены две ошибки первого варианта и их исправления: скрытая подпись поля фильтра теперь остаётся доступной вспомогательным технологиям; позднее подтверждение старой отправки больше не очищает черновик отдельно открытого нового чата. Тест переключения вызывает действительный обработчик «Новый чат» до подтверждения отправки.

Независимый запуск дал **41/41 успешных тестов**, без ошибок и пропусков; проверка TypeScript завершилась успешно. Четыре теста поведения проверяют однократное принятие отправки, сохранение отклонённых/новых черновиков, точный набор вложений и перенос таблицы без изменения общей ширины. Это проверки компонентов и функций; они не подменяют проверку браузера.

Разрешена сборка фронтенда: подтверждённых блокеров в проверенном коде не осталось. Проверяющий не менял приложение и не собирал обслуживаемый `dist`. Оформление dropdown использует нативную прогрессивную возможность CSS с резервным браузерным вариантом; отображение в установленном Chrome не проверено. Пояснение происхождения документов основано на backend-записях предыдущих загрузок и проверок; переименование/удаление этих документов пользователем не запрашивалось.

Предыдущие отчёты с детерминированным провайдером или иной автоматизацией не считаются новыми успешными проверками Chrome/LLM. Текущий результат: обзор кода и тесты пройдены, визуальный результат и новые ответы модели остаются непроверенными из-за остановки Computer Use.

Передача сборки: автор фронтенда сообщил о новых `index-EsyGj-Yw.js` и `index-D-YWOYLd.css`, ответе HTTP 200 и работоспособности API/agent/BGE/worker/Qwen. Патч из 56 файлов: SHA256 `057010805dd02f5f557fefbe3098957f9f21a5e1ead0bf7bc0bf64c40b381fb3`, заявлены чистое применение и проверка состава. Проверяющий подтвердил, что хеши проверенных исходников после упаковки не изменились. Доступность этих артефактов не подтверждает их отрисовку в Chrome. Передача частичная: цель визуальной и LLM-проверки полностью не достигнута.

Подробный рабочий протокол, идентификаторы исходных изображений и ожидаемые факты находятся в игнорируемом `.local/native_design_qa/review-only.md`; в публичном отчёте нет паролей и учётных данных.
